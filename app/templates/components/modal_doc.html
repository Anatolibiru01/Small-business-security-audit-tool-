Core Engine Attribution & Role

Lynislens is engineered on top of the battle-tested open-source audit engine Lynis, authored by Michael Boelen and maintained by CISOfy (cisofy.com/lynis).

Lynis Core Diagnostics Engine
  • Native UNIX Inspection: Audits PAM auth, SSH directives, sysctl kernel tunables, cron jobs, network interfaces, and crypto policies without third-party agent dependencies.
  • Alphanumeric Test Codes: Generates deterministic identifiers (e.g., AUTH-9288, SSH-7408, KRNL-5820, FIRE-4518).
  • Structured Report Generation: Emits raw key-value logs to /var/log/lynis-report.dat containing the base Hardening Index, installed packages, and raw finding tokens.
Lynislens Enterprise Value-Add
  • Enrichment & Remediation Knowledge Base: Enriches 700+ raw test codes into verified fix commands, configuration diffs, and risk explanations.
  • Governance & Compliance Crosswalk: Direct clause mapping to CIS Benchmark, NIST CSF v2.0, ISO 27001, PCI-DSS 4.0, SOC 2, and HIPAA.
  • Fleet Orchestration: Live SSE streaming, Paramiko SSH orchestrator, and zero-ingress cron push agents.

Security, Privilege Separation & Hardening Principles

Lynislens is engineered from the ground up to eliminate attack surface expansion while performing privileged diagnostic routines.

1. Least-Privilege Execution

The FastAPI suite runs under an unprivileged user (lynislens). Sudo elevation is restricted specifically to /usr/sbin/lynis via explicit sudoers entries without granting general root shells.

2. Cryptographic Token Rotation

Fleet agent ingestion uses cryptographically secure random entropy (secrets.token_hex(24)). Tokens can be instantly rotated or revoked from the Suite Settings panel.

3. Zero-Ingress Remote Surface

Remote push nodes never open inbound listening ports, socket daemons, or SSH credentials; communication is strictly outbound over encrypted TLS to the central dashboard.

4. Shell Injection Immunity

All command invocations use parameterized argument lists without shell expansion (shell=False) and strict input regex sanitization for IP addresses and hostnames.
