Enterprise Push Architecture (Zero Ingress Required)

Seamlessly audits servers across AWS, DigitalOcean, GCP, private VPCs, and local Kali VMs without open inbound ports or stored credentials.

1
Paste Command
Run this single command with root privileges on remote Linux.
2
Automated Lynis Setup
Lynis runs silently in background batch mode and schedules cron.
3
Sync to Hub
Pushes scorecard & findings directly to this dashboard.
curl -I http://127.0.0.1:8000/health
curl -sSL http://127.0.0.1:8000/install.sh | sudo bash -s -- --token [FETCHING_TOKEN] --server http://127.0.0.1:8000 --cron daily
Note: Replace 127.0.0.1 with your dashboard host's reachable LAN IP (e.g. 192.168.x.x) when running on external machines or VMs.

SSH Prerequisites & Non-Blocking Sudo:
Remote node must have Port 22 open. If sudo prompts for a password, automated scans will hang or show "Permission denied". Run the setup commands below on the target server first.
sudo systemctl enable --now ssh || sudo systemctl enable --now sshd
echo "$USER ALL=(ALL) NOPASSWD: /usr/sbin/lynis, /usr/bin/lynis, /opt/lynis/lynis" | sudo tee /etc/sudoers.d/99-lynislens-audit && sudo chmod 0440 /etc/sudoers.d/99-lynislens-audit
ssh <USERNAME>@<REMOTE_IP> "sudo lynis --version"
