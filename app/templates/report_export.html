Glossary & Methodologies

Lynis Hardening Index
A 100-point normalized metric reflecting the completeness of security controls, authentication safeguards, file protections, and kernel parameters against industry benchmarks.
CIS Benchmark Controls
Center for Internet Security consensus-based best practice guides for establishing a secure configuration posture across Linux enterprise environments.
Zero Trust Architecture
Security model requiring strict identity verification for every person and device attempting to access resources, regardless of network location.
Compensating Controls
Alternative security countermeasures designed to mitigate risk when standard security requirements cannot be directly implemented due to operational constraints.
